# LuminoAI Project Guidelines & Persistent Rules

## Language Policy (STRICT MANDATORY RULE)
- **100% English Only**: All user interface elements, labels, buttons, cards, toasts, logs, code comments, and documentation must ALWAYS be exclusively in English.
- **No Arabic in Code or UI**: Do NOT insert Arabic words or bilingual translations into the UI or codebase under any circumstances. Everything presented in the application must remain professional, clean, and in English.
